Nº 01 · Template Auto-Sorter · Read-only · Runs in your browser

Every email you’ve designed, sorted on one canvas.

Paste a Figma file link. The sorter reads every email frame in it and lays the whole library out by brand, flow or campaign, category and the sections each email is built from. Click any design to see it full size, then jump to it in Figma.

  • Nothing to install. It runs in this tab, on any computer.
  • Read-only. It never edits, moves or renames anything in your file.
  • Private. Your Figma token stays in this browser and is only sent to api.figma.com.
No library yet? Start from the starter file. Duplicate it in Figma. It’s already named the way the sorter reads.Open ↗

Sort a file

About a minute
  1. Copy it from the browser bar, or Share → Copy link. Pro sorts several files together, one link per line.
  2. Figma → Settings → Security → Generate new token, with File content: Read-only. · Why a token?
    1. In Figma, click your name (top left) and open Settings.
    2. Go to the Security tab and scroll to Personal access tokens.
    3. Click Generate new token, name it "Auto-Sorter", set File content to Read-only (leave the rest off), and create it.
    4. Copy the token right away (Figma shows it once) and paste it here.
