AI Template Library Auto-Sorter

Your Figma templates, sorted.

Paste a Figma file link and the sorter reads every email frame in it. Each template goes into a group by brand, campaign or flow, category and the sections it is built from, on one canvas you can drag around. Your Atomic Emails parts (atoms, molecules, organisms) get their own library. Click any card to open it in Figma.

  • Nothing to install. It runs in this tab.
  • Read-only. It never edits your file.
  • Private. Your token stays in this browser and is only sent to api.figma.com.
  1. One link per line if you want to sort several files together.
  2. Figma → Settings → Security → Generate new token. Turn on File content: Read-only.
    1. In Figma, click your name (top left) and open Settings.
    2. Go to the Security tab and scroll to Personal access tokens.
    3. Click Generate new token, name it "Auto-Sorter", set File content to Read-only (leave the rest off), and create it.
    4. Copy the token right away (Figma shows it once) and paste it here.
